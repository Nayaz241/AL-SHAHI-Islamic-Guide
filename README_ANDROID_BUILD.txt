AL SHAHI – Islamic Guide | Android APK build package

This package wraps the starter app in a native Android WebView shell and includes a GitHub Actions workflow to build a debug APK in the cloud. It is designed so the project owner can work from an Android phone; Android Studio on a PC is not required for this cloud build route.

BUILD FROM AN ANDROID PHONE
1. Download and extract this ZIP using your phone's Files app.
2. Sign in to GitHub in Chrome and create a new repository named AL-SHAHI-Islamic-Guide. Keep it Private if you prefer.
3. Upload the extracted project files and folders to the repository root. Make sure .github/workflows/build-apk.yml is included. GitHub's mobile website may be easier in Chrome with Desktop site enabled.
4. Open the repository's Actions tab. If prompted, enable Actions.
5. Select “Build AL SHAHI Android APK” and tap “Run workflow” (or wait for the first push build).
6. When the run finishes successfully, open that run and download the artifact named “AL-SHAHI-Islamic-Guide-debug-APK”.
7. Extract the downloaded artifact ZIP. Tap app-debug.apk and allow “Install unknown apps” for the browser/files app if Android asks.

TECHNICAL
- Native Android launcher app with offline local HTML/CSS/JS content.
- Package ID: com.alshahi.islamicguide
- Minimum Android: 6.0 (API 23); suitable for Android 11.
- compileSdk 37 / Android Gradle Plugin 9.5.0 / Gradle 9.6.0 / JDK 17.
- The APK generated by this workflow is a debug/test APK, not a Play Store release-signed APK.

CONTENT SAFETY / ACCURACY
This is an early app shell. It does not yet include a complete verified Quran, full English/Hinglish translation database, audio, or detailed reviewed prayer manuals. Before public distribution, add properly licensed texts and have qualified scholars review the Hanafi, Maliki, Shafi'i and Hanbali sections separately. Hadith entries need exact source references and grading; disputed devotional attributions must be labelled.
